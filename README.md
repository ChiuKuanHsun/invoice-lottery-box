# 對獎倉 Invoice Keeper

全自動統一發票收集兌獎機（Arduino 課程專題）的 three.js 3D 概念模型網站。

每天回家把發票一張張正面朝上投進去，機器分成電子發票盒和傳統發票盒疊起來收好；已開獎的期別當場顯示結果，未開獎的等開獎日在 OLED 顯示（或 LINE 推播）中獎發票在盒子裡由上數第幾張。

## 網站功能

- 切換硬體等級：**L1**（ESP32）／**L2**（ESP32＋筆電 OCR）
- 外觀、剖面、透視三種檢視，可顯示零件標籤
- 播放投入電子發票、傳統發票、皺掉的發票（退件）的流程動畫
- 模擬 11/25 開獎（115年09-10月）與按「已取出」更新盒內位置

## 硬體等級

| 等級 | 硬體 | 能做到 |
|---|---|---|
| L1 | ESP32＋GM65 條碼模組 | 分類、收集、記錄位置；WiFi 下載開獎號碼、LINE 推播；傳統發票只記錄位置 |
| L2 | L1＋USB 相機＋筆電 | 傳統發票拍照 OCR，也能自動兌獎；條碼與 OCR 都失敗時退件 |

## 本機執行

純靜態網頁，three.js 從 jsDelivr CDN 載入。直接用瀏覽器開 `index.html`，或：

```bash
python3 -m http.server 8000
```

然後打開 http://localhost:8000 。
